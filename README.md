# TemanDonor 🩸

TemanDonor is an open-source blood donation platform that connects donors 
with patients in urgent need through verified requests, real-time notifications, 
and a community-driven donor network.

## Status
🚧 Under active development

## Problem
Patients and families often struggle to find blood donors quickly during 
urgent situations. Current platforms are slow, not transparent, and lack 
real-time urgency features.

## Solution
TemanDonor connects blood donors, hospitals, blood banks, and patients 
through a centralized, transparent, and community-driven platform.

## Vision
To become Indonesia's most trusted and transparent blood donation platform —
starting from the Rhesus-negative community, scaling to nationwide.

## Tech Stack
| Layer | Technology |
|-------|-----------|
| Mobile | React Native + TypeScript |
| Web Dashboard | Next.js + TypeScript |
| Backend API | Node.js + Express + TypeScript |
| Database | PostgreSQL |
| Cache | Redis |
| Notifications | Firebase Cloud Messaging |

## Core Features
- Blood donor registration with QR code (PMI integration ready)
- Urgent donor notifications with smart matching
- Real-time blood stock transparency
- Donation history and impact tracking
- Community forum and chat with PMI/hospital admin
- Donor badges and achievements
